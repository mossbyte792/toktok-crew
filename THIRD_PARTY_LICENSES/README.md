# 제3자 구성요소 라이선스

- 글꼴 Jua (BM JUA, Woowahan Brothers). SIL Open Font License 1.1. 출처: https://github.com/google/fonts/tree/main/ofl/jua (확인일 2026-11-06, METADATA.pb license: OFL, OFL.txt 첨부). 앱의 res/font/jua_regular.ttf로 포함. OFL.txt 전문은 Jua_OFL.txt.
- OFL 요지: 글꼴은 자유롭게 사용·포함·배포할 수 있고, 글꼴 파일 자체를 단독으로 판매할 수 없다. 이 요지는 제출 전 사용자가 원문으로 한 번 더 확인한다.

- 앱에 포함된 jua_regular.ttf는 원본에서 KS X 1001 한글 2350자, 영문·숫자·기호만 남긴 서브셋(약 1.3MB, fontTools 4.68로 생성, 2026-11-06)이다. OFL상 수정본 배포가 허용되며 이 폴더의 Jua_OFL.txt를 함께 둔다. 서브셋에 없는 글자는 시스템 글꼴로 대체되어 표시된다.
